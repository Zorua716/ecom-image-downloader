产品介绍

把分散的商品图片，收拢成一个清晰流程

电商详情页里的商品图片往往来源分散、格式不一，手动一张张保存既慢又容易漏。这个扩展把「提取、预览、选择、下载」整合在一起。

01

告别手动找图

点击一次「获取图片」，即可扫描当前商品详情页中的图片，无需逐个右键保存。

02

格式不再混乱

JPG、WebP 等常见格式在下载时统一转换为 PNG，输出结果一致、便于整理。

03

只挑你要的

图片集中展示后可以逐张勾选，也可以全选，只下载真正需要的内容。

04

数据留在本地

图片在当前浏览器内处理，不上传到第三方服务器，只处理你正在浏览的页面。

核心功能

为高效整理商品图片而生

围绕「提取、预览、选择、下载」设计，操作路径短，界面干净。

一键提取

点击商品详情页右下角的「获取图片」按钮，自动扫描并收集当前页面的商品图片。

多平台适配

支持淘宝 / 天猫、京东、拼多多商家版的商品详情页，按站点封装适配逻辑，便于扩展。

集中预览

提取结果在独立页面以响应式网格展示，支持懒加载缩略图和大图预览。

自由选择

支持单张勾选、全选、取消全选，实时显示已选数量，选择体验直观。

PNG 统一导出

下载时自动把 JPG、WebP 等格式转换为 PNG，并按「商品标题_序号.png」命名。

本地处理

图片在当前浏览器内完成读取和转换，不上传云端，也不进行后台批量爬取。

使用流程

四步完成一次整理

  1. 1

    打开商品详情页

    进入受支持的淘宝、京东或拼多多商家版商品页面。

  2. 2

    点击「获取图片」

    点击页面右下角按钮，扩展自动扫描并收集图片。

  3. 3

    选择需要的图片

    在预览页勾选图片，支持全选和逐张选择。

  4. 4

    下载所选 PNG

    点击「下载所选」，文件保存到浏览器默认下载目录。

安装步骤

本地加载，即刻使用

通过 Chrome 开发者模式加载本地构建产物，全程无需上传或注册。

  1. 准备环境

    确保已安装 Node.js 18+ 与 Chrome 111+。

  2. 获取项目源码

    下载或克隆项目，并进入项目根目录。

  3. 安装依赖

    npm install

  4. 构建扩展

    npm run build

    构建完成后会生成 dist 文件夹，里面就是要加载的扩展。

  5. 打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions/ 并回车。

  6. 开启开发者模式

    打开页面右上角的「开发者模式」开关。

  7. 加载已解压的扩展

    点击「加载已解压的扩展程序」，选择项目中的 dist 文件夹。

  8. 开始使用

    打开支持的商品详情页，点击右下角的「获取图片」按钮即可。

提示：若安装依赖时遇到缓存目录权限错误（EPERM），可执行 npm install --cache .npm-cache 手动指定缓存位置。

常见问题

你可能想了解

为什么有的图片没有提取到？

需要登录、点击标签页才渲染，或通过 Canvas 等动态方式绘制的图片，无法通过页面扫描获取；懒加载内容会尽量通过受控滚动触发。

为什么部分图片下载失败？

部分图片地址存在防盗链或需要登录态，后台无法代取；失败的图片会在预览页单独列出，不会中断其他图片下载。

下载的图片为什么都是 PNG？

扩展会在下载时把 JPG、WebP 等可解码格式统一转换为 PNG，保证输出格式一致，便于后续整理和使用。

插件会上传我的图片吗？

不会。图片在当前浏览器内完成读取和格式转换，不上传到任何服务器，也不进行后台批量爬取。

支持哪些浏览器和版本？

目前面向 Chrome 111 及以上版本，基于 Manifest V3 实现；其他 Chromium 系浏览器可尝试通过开发者模式加载。

平台页面更新后还能用吗？

可以。扩展采用可扩展的站点适配器架构，平台页面调整后更新对应选择器即可恢复，无需重写整体逻辑。
